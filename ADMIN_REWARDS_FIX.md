# Admin Rewards Page Fix - Complete

## Root Cause
`getAdminDraws()` in `lib/api/admin.ts` was typed to return a paged object `{ page, size, total, entries: [...] }`, but the real `GET /api/v1/admin/rewards/draws` endpoint returns a **PLAIN ARRAY** (no wrapper, no `entries` field). This caused `response.entries` to be `undefined`, crashing the page with "Cannot convert undefined or null to object".

## What Was Changed

### 1. `lib/api/admin.ts` - Fixed Draw API Functions

#### `getAdminDraws()` - Fixed Shape & Removed Params
- **Before**: Called with `page`, `size`, `status` params and returned paginated object with `entries`
- **After**: 
  - Calls `GET /api/v1/admin/rewards/draws` with NO query params (backend doesn't support them)
  - Returns plain array: `AdminDrawDetails[]`
  - Defensive handling: `Array.isArray(response) ? response : Array.isArray(response?.entries) ? response.entries : []`
  - Client-side status filtering (if needed)
  - Ensures `prizeTiers` is always an array
  - Added dev logging to track the 500 error source

#### `getAdminDraw(id)` - Defensive Handling
- Added defensive `prizeTiers` coalescing: `prizeTiers: Array.isArray(response.prizeTiers) ? response.prizeTiers : []`

#### `getDrawWinners(id)` - Dev Logging
- Added `console.debug` of first winner object shape in development (to capture real response format when winners are selected)

#### Removed Invented Functions
- **DELETED**: `updateDraw()` - endpoint doesn't exist in v37 backend
- **DELETED**: `cancelDraw()` - endpoint doesn't exist in v37 backend
- **DELETED**: `UpdateDrawRequest` type

#### Updated Types

**`CreateDrawRequest`**:
- Removed `raffleCode` field (auto-generated by backend)
- Now only sends: `prizeName, scheduleLabel, startsOn, endsOn, drawDate, maxWinners, prizeTiers?`

**`AdminDrawDetails`**:
- Changed `startsOn`, `endsOn`, `drawDate` to `string | null` (legacy draws have null dates)
- Changed `status` to `"ACTIVE" | "CLOSED" | string` (only these 2 exist; others were invented)
- Made `createdAt`, `updatedAt` optional (not in real backend response)
- Made `prizeTiers` required but always coalesced to array

**`DrawWinner`**:
- Made ALL fields optional with `?` (real shape unknown until first winner selection)
- Added `rankPosition?: number` (actual backend field)
- Added `tierName?: string | null` (actual backend field)
- Added `prizeName?: string | null` (actual backend field)
- Kept legacy `tier`, `prize` for backward compatibility
- Added `[key: string]: unknown` for unknown fields

### 2. `app/admin/rewards/page.tsx` - Fixed Page Component

#### State & Handlers
- Removed `showCancelDialog` state
- Removed `handleCancelDraw()` function
- Updated `loadDraws()`: now expects plain array, defensive `Array.isArray(response) ? response : []`
- Updated `loadStandings()`: defensive array handling
- Updated `loadWinners()`: defensive array handling

#### Create Form
- Removed `raffleCode` field from `CreateDrawForm` interface
- Removed `raffleCode` input from modal
- Added note: "Raffle code will be auto-generated by the backend"
- Updated `handleCreateDraw()`: doesn't send `raffleCode` in payload
- Fixed tiers null-safety: `(tiers ?? []).length > 0 ? tiers : undefined`

#### Auto-Calculate Effect
- Fixed to handle undefined tiers: `(tiers ?? []).length > 0` and `(tiers ?? []).reduce(...)`

#### Date Formatting
- Updated `formatDrawDate()` to handle null: returns `"-"` for legacy draws
- Added `isNaN()` check to prevent "Invalid Date" display

#### Actions
- Updated `getActions()`: removed Cancel Draw button (only Close Draw and Select Winners remain)
- Comment updated: "ACTIVE/CLOSED only"

#### Status Filters
- Reduced filter buttons from 6 to 3: `["", "ACTIVE", "CLOSED"]`
- Removed invented statuses: UPCOMING, COMPLETED, CANCELLED

#### List View
- Protected draw list: `(draws ?? []).map(...)`
- Protected `entryCount`: `(draw.entryCount ?? 0).toLocaleString()`

#### Detail View
- Protected `entryCount`: `(selectedDraw.entryCount ?? 0).toLocaleString()`
- Protected prize tiers: `(selectedDraw.prizeTiers ?? []).length > 0`
- Removed Cancel Draw dialog

#### Standings View
- Protected standings map: `(standings ?? []).map(...)`
- Protected prizeTiers: `getProjectedTier(entry.position, selectedDraw.prizeTiers ?? [])`

#### Winners View
- **FULLY NULL-SAFE**: Every field uses optional chaining or nullish coalescing
- Changed "User ID" column to "Rank" showing `rankPosition ?? idx + 1`
- Read `tierName ?? tier` for backward compatibility
- Read `prizeName ?? prize` for backward compatibility
- All cell values: `winner.displayName ?? "-"`, `winner.points?.toLocaleString() ?? "-"`, etc.
- Date formatting: `winner.selectedAt ? new Date(...) : "-"`
- Column headers conditional on field existence: `winners.some(w => w.tier || w.tierName)`
